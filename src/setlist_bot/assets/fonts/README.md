# Noto Sans

Unmodified regular and bold Noto Sans fonts, distributed under SIL OFL 1.1;
see LICENSE.txt. Source: https://github.com/notofonts/noto-fonts

Bundled with the application so PDF generation works offline and in Docker,
with embedded Cyrillic glyphs and consistent print metrics.


Дополнительно встроены неизменённые Regular/Bold из системных пакетов Ubuntu:
Open Sans (`fonts-open-sans`), DejaVu Sans (`fonts-dejavu`), Liberation Sans
(`fonts-liberation`), Noto Serif (`fonts-noto-core`). Лицензии и уведомления
сохранены в `LICENSE-open-sans.txt`, `LICENSE-dejavu.txt`,
`LICENSE-liberation.txt`; Noto Serif распространяется по OFL в `LICENSE.txt`.
Все пять семейств используются локально, без обращения к сервисам шрифтов.
