# Инструкции для Codex

1. Главный продуктовый документ: `TECH_SPEC.md`. Сначала прочитай его полностью.
2. Реализуй систему поэтапно. Начни с ядра (роли, группы, библиотека), не с QR-голосования.
3. Разделяй согласованные требования, технические рекомендации и открытые вопросы из раздела 14.
4. Любую новую функциональность сопровождай тестами и короткой инструкцией запуска.
5. Предпочитай Python, типизацию, чистую архитектуру, PostgreSQL, Alembic, Docker Compose; перед выбором конкретного стека предложи компактное обоснование.
6. Соблюдай разграничение прав и изоляцию групп; личные черновики не должны раскрываться другим участникам.
7. Не помещай секреты и Telegram-токены в Git, используй `.env.example`.
8. Импорт/экспорт, версионность и архив должны сохранять целостность данных; любые разрушительные действия подтверждай.
9. Для первой задачи предложи структуру репозитория, план MVP и список минимальных проверок, затем реализуй только согласованный первый этап.
