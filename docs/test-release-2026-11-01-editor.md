# Тестовый выпуск: средняя пауза и история редактора

## Изменения

- Средняя пауза в шапке Mini App: целое число секунд, 0 допустим. Список и средняя
  сохраняются атомарно одной версией существующего личного черновика.
- Порядок истории: непустые общие версии текущего выступления, от последней к первой,
  затем последние утверждённые списки прошлых выступлений, от новых к старым.
- Для пустого выступления без общих версий первой идёт рекомендация: совпадение типа,
  затем близость фактической длительности, затем более свежая дата. Далее хронология,
  без повтора рекомендованного выступления. При отсутствии типа/времени пропускается
  соответствующий критерий. Чужие личные черновики не используются.
- Прямой запуск редактора из кнопок «Предложить свой вариант» и «Изменить».
  Остальные способы [сохранены за флагом](archive/setlist-input-methods.md).

Новых миграций и копирования данных нет; схема остаётся `f2d7c614a083`.
Этот выпуск не содержит ранее записанного личного уведомления после публикации.

## Обновить только тестовый контур на VPS

Основной бот и его БД не обновляются. Существующее подключение общего Caddy
сохраняется, включая основной hostname.

```bash
(
  set -e
  cd /opt/setlist_bot_sandbox
  test -z "$(git status --porcelain)"
  git switch feature/web-admin
  git pull --ff-only origin feature/web-admin
  bash scripts/update-sandbox-admin.sh server
)
```

Не запускайте одновременно облачный polling этого же тестового бота.
Данные из локальной тестовой базы на сервер не отправляются.

## Ручная проверка

1. Из группы нажмите «Предложить свой вариант», из личного черновика — «Изменить»:
   редактор открывается сразу. Два участника получают разные личные черновики.
2. Две песни подряд: средняя 5 → 30 должна добавить 25 секунд к итогу, 0 убрать
   среднюю. Отдельная пауза 3 минуты не меняется. «Отменить» возвращает прежнюю среднюю.
3. Закройте после «Сохранено», откройте снова: средняя и порядок сохранены,
   общий список не изменился. Сохранение не означает утверждение или публикацию.
4. У пустого выступления с типом первым по ← показан подходящий по типу список,
   даже если у другого типа длительность ближе. Затем ближайшая длительность и дата.
5. У выступления с общими версиями ← показывает последнюю, предыдущие, затем прошлые
   выступления. → возвращает к вводу. «Взять за основу» переносит список и среднюю,
   «Отменить» возвращает их. Одного просмотра недостаточно для замены.
6. Ограничьте предложения администраторами: участник не редактирует список и может
   перейти к запросу прав у владельца. Существующие правила утверждения сохранены.
