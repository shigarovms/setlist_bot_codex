# Основной выпуск: редактор и регистрация — 1 ноября 2026

Подготовлен перенос накопленного тестового функционала после основного выпуска
`cbf52e6`. Последняя правка — понятное сообщение `/new_band` в личном чате,
без запуска регистрации. Полный список изменений — в CHANGELOG.

## Что входит

- Прямой вход в Mini App из «Предложить свой вариант» в группе и «Изменить» в личке.
  Временная история: общие версии текущего выступления, затем прошлые утверждённые
  списки. Для пустого списка первой идёт рекомендация по типу, длительности и дате.
- Кнопки «Отменить · Сред. пауза · + Пауза». Средняя сохраняется в личном черновике;
  при правке администратором наследуется также **новыми** сет-листами коллектива.
  Уже существующие списки и чужие черновики не переписываются.
- Один язык PDF: EN с транслитерацией, RU с исходными названиями. Прежние файлы
  не перезаписываются, старые кнопки совместимы с новым правилом.
- `/new_band` вместо `/group` в меню, справке и подсказках. Старое имя работает
  скрытым алиасом. Шаги регистрации и подтверждение владельцем чата сохраняются.
- Короткий согласованный `/start` из трёх пунктов, RU/EN до 512 символов.
- Старые способы набора сохранены за `SETLIST_LEGACY_INPUT_ENABLED=true`.

Записанное ранее личное уведомление после публикации из Mini App по-прежнему
в очереди и в этот выпуск не входит.

## Границы обновления

Перед публикацией пройден полный набор: **524 Python-теста**, включая Chromium
и проверки реальных ограниченных ролей PostgreSQL; **7 JavaScript-тестов**,
Ruff, форматирование, mypy, `uv lock --check` и синтаксис скриптов выпуска.
Тестирование выполнено последовательно на отдельной `setlist_test`, не на рабочих
базах. Работающее обновление на VPS проверяется отдельно после команды ниже.

Сервер один — `212.192.217.128`. Основной проект `/opt/setlist_bot_codex`, БД `setlist`,
бот @setListDuration_bot. Тестовый проект `/opt/setlist_bot_sandbox` и его БД
`setlist_sandbox` не обновляются следующей командой. Данные из облачной `_test`-базы
или серверного sandbox не копируются. Календарные ссылки, ключи и пароли сохраняются.

Схема остаётся **f2d7c614a083**, новых миграций в этом обновлении нет. Штатный скрипт
всё равно проверяет схему и резервную копию. Для уже установленного Mini App он
добавляет только `UPDATE(default_pause_seconds)` роли `setlist_miniapp` в **основной**
БД. Приложение повторно проверяет роль администратора; прочие поля коллектива,
общий сет-лист, каталог и утверждения остаются недоступны для записи HTTP-сервису.

Предполагается, что основной Mini App и календарь уже настроены по
[первой инструкции](production-release-2026-11-01.md). Адрес Mini App прежний:
`https://setlist-212-192-217-128.sslip.io/miniapp/`. BotFather заново настраивать не нужно.

## Выполнить на сервере

```bash
(
  set -e
  cd /opt/setlist_bot_codex
  test -z "$(git status --porcelain)"
  git switch main
  git pull --ff-only origin main
  git log -1 --oneline
  bash scripts/release-production.sh
)
```

Скрипт собирает образы, делает копию **основной** БД и репетирует миграции на новой
временной базе на том же сервере. Проверяет количество строк основных таблиц и удаляет
только временную копию. После успеха останавливает основной polling и его HTTP-сервисы,
делает свежий backup, проверяет схему, применяет точечное SQL-разрешение, проверяет
health и запускает основной бот. Рабочая база не восстанавливается из дампа.

Общий Caddy и тестовый polling не пересоздаются. Полный вывод скрипта не содержит
токенов или паролей; частные `.env.*`, дампы и `docker inspect` в чат не отправляйте.

## Проверка после запуска

1. `/start` — три пункта, `/new_band` в личке — объяснение о регистрации в общем чате.
2. В меню группы — `/new_band`, без `/group`; в справке RU/EN используется новое имя.
3. Свои прежние песни, выступления, варианты и утверждённые PDF доступны.
4. «Изменить» открывает редактор, три кнопки стоят в нужном порядке. Просмотр истории
   не меняет ввод, «Взять за основу» и отмена работают, публикация требует кнопки.
5. Администратор меняет среднюю, дожидается сохранения и создаёт новое выступление:
   оно наследует паузу. У старого выступления общий список прежний.
6. Экспорт EN — латинские названия, RU — исходные; отдельной транслитерации нет.

```bash
cd /opt/setlist_bot_codex
docker compose exec -T bot .venv/bin/setlist-bot --check
docker compose ps
docker compose logs --tail 30 bot calendar miniapp
```

Ожидаются `PostgreSQL OK; migration f2d7c614a083`, healthy для обоих HTTP-сервисов
и основной polling ID **7430933141**. Если скрипт остановился с ошибкой, сохраните
backup и вывод ошибки; не делайте downgrade или восстановление поверх основной БД.
