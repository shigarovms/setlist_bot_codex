## Обновление тестового контура на VPS

```bash
(
  set -e
  cd /opt/setlist_bot_sandbox
  git status --short
  test -z "$(git status --porcelain)"
  git switch feature/web-admin
  git pull --ff-only origin feature/web-admin
  bash scripts/update-sandbox-admin.sh server
)
```

Скрипт собирает образ, сохраняет резервную копию серверной тестовой базы, проверяет
схему и перезапускает только тестовые сервисы. Облачная база не переносится.
При наличии несохранённых исходников или невозможности fast-forward процедура
должна остановиться: не заменяйте это на `reset --hard`.
Не запускайте второй polling-процесс с токеном тестового бота.

```bash
docker compose -f compose.sandbox.yaml exec -T bot .venv/bin/setlist-bot --check
docker compose -f compose.sandbox.yaml logs --tail 50 bot
```

Ожидается `PostgreSQL OK; migration d71f439e8a20` и polling тестового бота.
Если основной контур ещё на старой схеме, его раздел в общей админке может ожидать
отдельного согласованного обновления. Основной Telegram-бот продолжает работать.

## Проверка с телефона

1. В коллективе с одним составом создайте выступление. Текст — «Сейчас проверю
   занятость участников перед отправкой приглашений.» Проверьте занятость и отправьте
   приглашения: доставка без искусственной паузы, повторные нажатия не дают дублей.
2. Назначьте себя на роль как администратор: участие сразу подтверждено, отдельного
   личного приглашения нет. Для другого человека требуется ответ. Если вы заняты,
   предупреждение и явное разрешение пересечения сохраняются.
3. Получите ответ участника: уведомление администратора содержит переход к составу,
   без просмотра сет-листа/PDF и личных кнопок приглашённого. Запросите подмену,
   проверьте подбор и отдельное одобрение согласившегося кандидата.
4. В `/my_gigs` откройте своё подтверждённое участие: есть «Открыть сет-лист»,
   без кнопки печати. До утверждения открывается актуальный общий рабочий список,
   после утверждения — утверждённый с экспортом под ним. После возврата в работу
   экспорт недоступен. Чужие личные черновики не отображаются.
5. Создайте более восьми ролей. Текст на обеих страницах полный, включая последнюю
   роль. У подтвердивших — ✅ и имя внутри коллектива; у остальных — только роль.
   Переключаются лишь кнопки. Введите «Звукорежиссер» вместо ранее сохранённого
   «звукорежиссер»: большая буква сохраняется и в тексте, и на кнопке.
6. Верхней кнопки изменения состава нет. Через нижнюю «Составы [коллектив]» выберите
   и примените другой состав: должно измениться именно открытое выступление после
   подтверждения, а не соседнее. Проверьте старые кнопки и действия неадминистратора.
7. При отмене участия старый переход к сет-листу больше не открывает его гостю.
   Чужая кнопка не даёт доступа. Доступ к PDF музыкантов/световика под утверждённым
   списком сохраняется, включая ранее согласованную пустую строку паузы.

Обновление основного контура — отдельный шаг после этой проверки.
