# Создание выступления одной строкой

В личке выберите коллектив, в группе используется её коллектив. `/concert` или
«Новое выступление» открывает ForceReply. Быстрый `/concert Дата …` тоже работает.

Дата идёт первой. Название, длительность, тип, город и информация необязательны;
распознаваемые дополнительные поля можно переставлять. Разделители — два и более
пробела или точка с пробелом. Примеры в запросе бота:

```text
23.04 Клуб Космос. 45мин. Сольник. Москва
```

```text
25 декабря 2027 Арарат арена  Ереван  корп  31 мин
```

```text
15дек Летний парк  Питер  корп  1:25:00
```

Без года дата означает ближайшее вхождение, включая сегодня. В подтверждении
всегда указан год и все распознанные поля. «Изменить данные» открывает новый запрос;
прежнее подтверждение перестаёт действовать. Создание — только после «Подтвердить»,
с повторной проверкой прав администратора. `/cancel` отменяет ввод.

Длительность: `45мин`, `1ч15мин`, `1:15` (часы:минуты), `1:25:00` (часы:минуты:секунды).
Число без единиц — минуты. Противоречивые значения одного поля требуют исправления.
Типы: Сольник (концерт, сольное выступление…), Корпорат (корп, корпор, корпоратив,
заказняк…), Фест (фестиваль). Примечания распознаются целыми фрагментами: слова
«концерт» или «Москва» внутри длинного комментария не превращают его в тип/город.

Города: локальный индекс около 55 тысяч названий/вариантов на базе GeoNames;
без сетевого обращения при создании. Он покрывает города примерно от 15 тысяч
жителей и кириллические альтернативы. Это распознавание подписи, без определения
координат/страны для одноимённых городов. «Питер», «СПб» → «Санкт-Петербург».

Первый нераспознанный фрагмент становится названием, следующие — дополнительной
информацией. Для редкого города или неоднозначного названия можно указать поля явно:

```text
23.04 Название: Москва. город: Любой небольшой город. тип: Акустика. инфо: Под плюс
```

Все поля можно позже изменить в «Параметрах выступления». Подсказки о заполнении
после создания сохраняются; заполненные кнопки предлагают изменить значение.

## Article по умолчанию

Новые коллективы используют Article с тремя столбцами: номер, название, длительность.
Миграция `f2d7c614a083` меняет прежний неявный mono на Article; зафиксированный
в аудите ручной выбор mono сохраняется. «Параметры сет-листа» позволяют выбрать mono.
Песни, выступления, черновики, версии и PDF не переписываются. При downgrade сохраняются
выбранные группами стили, меняется только default создания.
