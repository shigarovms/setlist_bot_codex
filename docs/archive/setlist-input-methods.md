# Архив интерфейсов ввода сет-листа

С 1 ноября 2026 основной интерфейс — Mini App. Два прежних способа не удалены и не
продублированы в отдельной папке: это действующие, проверяемые адаптеры за флагом.
Их можно вернуть без отката редактора, миграций и изменения сохранённых данных.

Код:

- `transport/controller.py`: `_legacy_suggestion_prompt`, `_text_suggestion`,
  `_selection_action`, `selection_input`, `_selection_view`.
- `application/song_selection.py`: временная сессия Reply Keyboard.
- `application/command_inputs.py`, `application/templates.py`: текстовые ответы.
- Оба способа используют `application/setlists.py` и существующий личный черновик.

Чтобы вернуть меню «Открыть редактор / Ввести списком / Выбрать песни», в частном
`.env` нужного контура задайте:

```dotenv
SETLIST_LEGACY_INPUT_ENABLED=true
```

Для серверного тестового контура примените `bash scripts/update-sandbox-admin.sh server`.
Основной контур обновляется отдельно по инструкции выпуска. Новые карточки и
возврат в основное меню получают прежний callback вместо прямой ссылки Mini App.
Существующие ссылки/черновики продолжают работать. Для возврата к эксперименту —
`false` и такое же обновление. При отсутствии настроенного Mini App прежние способы
доступны автоматически, чтобы бот оставался работоспособным.

Текстовые `/suggestion` и ответы списком на уже существующие сообщения сохраняют
совместимость. Старые callback обрабатываются с прежними проверками владельца,
прав, версии и срока действия. Ничего из этого не публикует черновик автоматически.

Регрессии: `tests/test_song_selection.py`, `tests/test_suggestion_replies.py`,
`tests/test_miniapp_group.py` и
`tests/test_miniapp_navigation.py`.
