# Mini App личных черновиков — тестовый выпуск

HTML-редактор — третий способ ввода рядом со списком и клавиатурой песен.
Открывается кнопкой «🖐 Открыть редактор» **только в личке** после «Изменить» или
«Предложить свой вариант». Групповые кнопки работают как прежде.

## Как пользоваться

1. Добавляйте песни кнопкой `+` или перетаскивайте за ручку `⋮⋮` из репертуара
   в список. В каталоге поиск и страницы по 40 песен, сортировка по популярности.
2. Переставляйте за ручку; удаляйте крестиком или перетаскиванием в область
   «Убрать из сет-листа». Повторы сохраняются. Пауза добавляется отдельно:
   `3` — три минуты, `3 сек` / `00:00:03` — три секунды.
3. Стрелка влево показывает прошлые выступления этого коллектива: последнюю
   утверждённую версию каждого, от свежих к старым. Вправо можно вернуться к
   текущему вводу. Просмотр ничего не заменяет; «Взять за основу» копирует список.
   Общая пауза остаётся настройкой текущего черновика, названия/длительности песен
   берутся из актуального каталога. Паузы и повторения источника сохраняются.
4. «Отменить» возвращает предыдущий шаг редактирования (до 50 шагов).
5. «Сохранить черновик» сохраняет **только обычный личный черновик**. После
   «Вернуться к боту» используйте штатные кнопки изменения/публикации.
   Сохранение не отправляет вариант группе и не утверждает сет-лист.

Сверху показаны текущая и запланированная длительности. Паузы не нумеруются;
при 10 и более песнях номера 01, 02… Тема меняется вместе с Telegram, без потери ввода.
До сохранения ввод живёт в открытом окне; при закрытии Telegram предупреждает об
изменениях. При конфликте показывается актуальный черновик, свой ввод остаётся на
экране и его можно скопировать. Для продолжения загрузите актуальный вариант.
Удалённые/архивные песни не подменяются автоматически, интерфейс предложит их убрать.

## Установка на существующем VPS: только sandbox

Основной бот не обновляется. Рабочая ветка — `feature/web-admin`.
Календарный HTTPS уже должен работать на `212-192-217-128.sslip.io`, порты 80/443 открыты.
Настройка BotFather не требуется для Inline-кнопки WebAppInfo в личном чате;
кнопка появляется после успешной установки HTTPS-сервиса.

Выполните на сервере:

```bash
(
  set -e
  cd /opt/setlist_bot_sandbox
  test -z "$(git status --porcelain)"
  git switch feature/web-admin
  git pull --ff-only origin feature/web-admin
  git log -2 --oneline
  bash scripts/update-sandbox-admin.sh server
  python3 scripts/setup-sandbox-miniapp.py
)
```

Первый скрипт собирает общий образ и сохраняет **собственную серверную тестовую БД**,
проверяет её схему и запускает тестовый контур. Установщик добавляет отдельный процесс
`miniapp` и ограниченную SQL-роль, проверяет HTTPS, затем включает кнопку в боте.
Если до этого календарный HTTPS ещё не настраивался, перед установщиком Mini App:

```bash
python3 scripts/setup-sandbox-calendar.py --host 212-192-217-128.sslip.io
```

Не запускайте параллельно облачный polling того же тестового бота. Базы между
контурами не копируются. Новых таблиц и миграций для Mini App нет: схема остаётся
`c04f7a92d531`. Ранее запрошенные правки дат и меню — отдельный предшествующий коммит
`d1ec39d`, их откат Mini App не затрагивает.

Повторное обновление: `git pull --ff-only origin feature/web-admin`, затем
`bash scripts/update-sandbox-admin.sh server`. Наличие `.env.miniapp` включает сервис
в обновление автоматически. После смены токена **тестового** бота повторите
`python3 scripts/setup-sandbox-miniapp.py`, чтобы обновить производный ключ проверки.

## Устройство и ограничения

- `miniapp` — aiohttp на 8091, доступен только через маршрут `/miniapp/` в Caddy.
  Админка остаётся доступна через SSH-туннель; её HTTP-маршруты наружу не публикуются.
- Vanilla HTML/CSS/JS, без сборки фронтенда и сторонних UI-зависимостей.
- Сервер проверяет подпись Telegram initData, срок до часа, пользователя, членство,
  право предлагать варианты, неизменную цель сессии и версии черновика/каталога.
  Сессия кнопки действует 24 часа; после истечения авторизации откройте её заново.
- `.env.miniapp` имеет права 600, содержит отдельный пароль БД и производный ключ
  проверки initData. **Не публикуйте его**. Токен Bot API, ключ календарных ссылок
  и пароли админки в публичный процесс не передаются.
- SQL-разрешения: чтение данных редактора, создание/правка личного черновика,
  служебной сессии и запись аудита. Нет записи в общий сет-лист, каталог, утверждения
  и поддержку. Колонка id коллективов/участий доступна для UPDATE только ради
  `SELECT FOR UPDATE`; код редактора идентификаторы не изменяет.
- 192 MiB памяти, 0,75 CPU, пул 3 соединения, не более 4 одновременных API-запросов,
  до 200 позиций/5000 песен каталога. Локальные перетаскивания не обращаются к серверу.
- Сохранение вызывает `Setlists.edit_songs(private=True)`. Отдельной таблицы или
  независимой процедуры сохранения нет. Повтор отправки того же запроса не создаёт
  новую версию; устаревший ввод не перезаписывает черновик.

## Проверка после установки

1. В личке тестового бота откройте выступление → «Изменить» / «Предложить свой
   вариант» → «Открыть редактор». В общем чате этой кнопки быть не должно.
2. Добавьте одну песню дважды, ещё одну, паузу `3`; переставьте, удалите и отмените
   удаление. Проверьте порядок, повторы, длительность и отсутствие номера у паузы.
3. Отлистайте три прошлых утверждённых выступления, вернитесь вправо: ввод остался.
   Снова откройте прошлое и нажмите «Взять за основу», внесите изменение.
4. Смените тему Telegram: список и изменения остаются, цвета обновляются.
5. Сохраните и вернитесь к боту: это личный черновик, в группе ничего не изменилось.
6. Откройте тот же черновик на другом устройстве, сохраните разные правки:
   второй устаревший запрос показывает конфликт и текущий вариант.
7. Проверьте старые способы ввода, перенос даты с подтверждением года,
   «Мои коллективы» и возврат к выступлениям из подписки.

Диагностика, не выводящая секреты:

```bash
docker inspect --format '{{.State.Status}} {{if .State.Health}}{{.State.Health.Status}}{{end}}' setlist-sandbox-miniapp-1
docker logs --tail 30 setlist-sandbox-miniapp-1
curl -fsS -o /dev/null -w '%{http_code}\n' https://212-192-217-128.sslip.io/miniapp/
```

Ожидается `running healthy` и HTTP 200. API без Telegram-авторизации должен
отказать; успешная загрузка HTML сама по себе не открывает данные.

## Откат только эксперимента Mini App

Все изменения редактора — один коммит с заголовком
`feat: add private Telegram Mini App editor`. Найти его:

```bash
git log --oneline --grep='^feat: add private Telegram Mini App editor$'
```

После выбора точного SHA, в **sandbox**:

```bash
docker stop setlist-sandbox-miniapp-1
git revert <SHA_коммита_Mini_App>
bash scripts/update-sandbox-admin.sh server
docker restart setlist-sandbox-calendar_proxy-1
```

Штатный скрипт уберёт кнопку редактора, restart применит прежние маршруты Caddy.
Отдельный остановленный контейнер может остаться: удалите его обычным
`docker rm setlist-sandbox-miniapp-1`. `.env.miniapp` остаётся частным неиспользуемым
файлом; базу/тома не удаляйте. Сохранённые редактором обычные личные черновики остаются
доступны, восстановление БД и откат миграций не нужны. Если поверх эксперимента
появятся новые коммиты с зависимостями, сначала проверьте получившийся revert.
