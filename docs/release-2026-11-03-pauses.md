# Тестовый и основной выпуск: подписи пауз — 3 ноября 2026

## Изменения

- При добавлении паузы можно ввести сценическую ремарку или оставить текст пустым.
  После добавления подпись/карандаш открывает редактирование текста и длительности.
  Отмена сохраняет прежние значения. Текст — до 1000 символов.
- Подпись сохраняется через обычные личные черновики, предложения, общие и
  утверждённые списки, историю, Article, админку и оба PDF. Пустой текст не заменяется
  словом «пауза». Стандартные подписи продолжают переводиться; пользовательские
  не переводятся автоматически, в EN-PDF применяется обычная транслитерация.
- Прозрачный фон и пунктир у строк пауз вместо тёмного фона предыдущего выпуска.
- «← прошлые» — шрифт как у «Текущий черновик»; кнопки слева и справа одной ширины.
- Для основного контура включены также предыдущие тестовые правки мобильного поиска:
  очистка при новом входе, поднятие поля наверх, снятие фокуса при других действиях,
  нижняя пунктирная «+ пауза» и отсутствие области удаления.

Проверки перед публикацией: **575 Python-тестов** на отдельной `setlist_test`,
включая миграции, права SQL-ролей, многостраничные PDF и мобильный Chromium;
**9 JavaScript-тестов**, Ruff, форматирование, mypy, lock-файл и синтаксис скриптов.
Тесты не используют настоящий Telegram и не меняют серверные базы.

## Схема и данные

**a1426785384d → b63e2a71d940**: одно nullable-поле `items.pause_label` с ограничением
длины и принадлежности к паузе. NULL оставляет прежнюю стандартную подпись;
пустая строка хранит намеренно пустую подпись. Исторические JSON-снимки не обновляются.
Новые подписи проходят через существующую систему снимков и версий.
Лимит тела авторизованного запроса Mini App поднят до 1 MiB, чтобы помещались
допустимые 200 позиций с длинными Unicode-подписями. Превышение лимита отклоняется.

Тестовый и основной контуры находятся на одном VPS, но обновляют свои базы отдельно:

| Контур | Каталог | База | Ветка |
| --- | --- | --- | --- |
| Тестовый | `/opt/setlist_bot_sandbox` | `setlist_sandbox` | `feature/web-admin` |
| Основной | `/opt/setlist_bot_codex` | `setlist` | `main` |

Код публикуется в GitHub; это не перезапускает VPS. `.env.*`, токены, ключи,
календарные ссылки и тома PostgreSQL остаются на сервере. Данные локальных тестов
или sandbox в основную базу не копируются. Дополнительные сервисы и настройки
BotFather не требуются; SQL-роли сохраняют прежние ограничения.

## Сначала тестовый контур

В консоли VPS выполните:

```bash
(
  set -e
  cd /opt/setlist_bot_sandbox
  test -z "$(git status --porcelain)"
  git switch feature/web-admin
  git pull --ff-only origin feature/web-admin
  git log -1 --oneline
  bash scripts/update-sandbox-admin.sh server
)
```

Скрипт соберёт образ, сохранит резервную копию **серверной тестовой базы**, выполнит
миграцию и проверит сервисы перед запуском тестового polling. Основной бот и его
база не обновляются. Раздел основного контура в общей админке временно недоступен
до отдельного обновления основной схемы — сам основной бот продолжает работу.
Не запускайте параллельно второй polling с токеном тестового бота.

Проверка:

```bash
cd /opt/setlist_bot_sandbox
docker compose -f compose.sandbox.yaml exec -T bot .venv/bin/setlist-bot --check
docker compose -f compose.sandbox.yaml logs --tail 30 bot
```

Ожидается `PostgreSQL OK; migration b63e2a71d940` и ID тестового бота `1110437563`.
Полностью закройте старое окно Mini App и откройте редактор заново.

### Проверка с телефона

1. Добавьте паузу с текстом «Крабы уносят микрофонную стойку» и длительностью `3`.
   Подпись появилась, общее время выросло на три минуты, нумерация песен не изменилась.
2. Нажмите подпись/карандаш, измените только текст и примените. После автосохранения
   закройте и снова откройте редактор: текст сохранился, длительность прежняя.
3. Очистите текст и примените: слово «пауза» не возвращается. Затем попробуйте
   изменить текст и нажать «Отмена»: пустая подпись остаётся.
4. Добавьте обычную паузу, ничего не меняя в поле текста: стандартная подпись
   осталась. Переставьте паузы, удалите одну и отмените удаление.
5. Отправьте вариант в группу, примените и утвердите. Проверьте текст и пустую
   подпись в Telegram, Article и PDF музыканта/световика. Откройте историю/новый
   черновик на основе этого списка: подписи сохраняются.
6. В обеих темах паузы прозрачные; обе стрелки истории одинаковой ширины,
   «← прошлые» и «Текущий черновик» одинакового размера шрифта.
7. Проверьте поиск после этих действий: очистка при повторном входе, поле наверху,
   клавиатура закрывается при действии вне поля. Реальную клавиатуру проверяйте
   в Telegram на iPhone/Android.

## Затем основной контур

После успешной проверки тестового бота выполните отдельно:

```bash
(
  set -e
  cd /opt/setlist_bot_codex
  test -z "$(git status --porcelain)"
  git switch main
  git pull --ff-only origin main
  git log -1 --oneline
  bash scripts/release-production.sh
)
```

Скрипт сначала восстанавливает резервную копию **основной** базы в новую временную
базу и проверяет миграцию там. Только после успешной репетиции останавливает основные
приложения, делает свежую копию, мигрирует основную базу и проверяет сервисы перед
запуском polling. Дамп не восстанавливается поверх рабочей базы.

```bash
cd /opt/setlist_bot_codex
docker compose exec -T bot .venv/bin/setlist-bot --check
docker compose ps
docker compose logs --tail 30 bot calendar miniapp
```

Ожидаются схема `b63e2a71d940`, ID основного бота `7430933141` и healthy у HTTP-сервисов.
Свои прежние песни, выступления, черновики, PDF и календарные ссылки должны сохраниться.
Оба контура админки снова станут совместимы после обновления основной схемы.

При ошибке не продолжайте обновление. Сохраните путь к backup и журнал ошибки;
не выполняйте принудительный downgrade или восстановление поверх основной базы.
Откат миграции при наличии подписей, включая пустые, намеренно запрещён:
проверьте [инструкцию восстановления](operations.md).
